# credit-card-fraud-detection
This report outlines machine learning model building and evaluation for fraudulent transaction detection from a dataset with attributes such as transaction distance, ratio of price, and transaction type.
Fraudulent credit card transaction detection is a critical task for banks to prevent monetary loss and customer mistrust. This report outlines machine learning model building and evaluation for fraudulent transaction detection from a dataset with attributes such as transaction distance, ratio of price, and transaction type. Specifically, the target variable is a binary variable indicating whether a transaction is fraud or not (fraud). Decision Trees, K-Nearest Neighbors (KNN), and linear regression (for experiment's sake only) are the three models that were trained and evaluated. Visualizations are added to the report to display information regarding data and model performance.
